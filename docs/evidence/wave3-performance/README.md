# Wave 3 import timing diagnostics

Instrumentation schema (milliseconds unless stated otherwise): `wasm_dispatch_ms` covers Rust input parsing, execution, Rust response serialization, and WASM-to-JS string conversion together; `worker_parse_ms` covers JSON.parse of that string; `post_start` and `post_end` are absolute Worker performance timestamps around the response `postMessage`, correlated by request ID; `receive` is the corresponding absolute main-thread timestamp. `post_end - post_start` measures synchronous sender-side structured-clone and enqueue cost; `receive - post_start` measures elapsed send-to-handler latency, including cloning, scheduling and delivery. These overlap and must not be added. Cross-context clocks use `performance.timeOrigin + performance.now()` and can have browser precision rounding. `clone_ms` and `structural_ms` cover each repository parse invocation; `idb_ms` covers the write transaction; `equality_ms` covers complete response comparison. Console records may also contain non-reproduction operations; filter by operation and correlate requests. The patch does not alter equality, authorization or deadlines.

`rss-samples.log` samples all Chromium processes once per second, including unrelated browsers if present. Individual RSS values are not additive physical memory because pages may be shared. The largest sample is a lower bound on the largest observed process peak, not a true peak, and does not distinguish WASM, JS or rendering. Sampling perturbs timing. The historical binary exposes no internal timing boundary: computing a separate Rust calculation-versus-serialization split requires a separately rebuilt diagnostic binary; combined dispatch must not be attributed to computation alone.

From a clean checkout at `3435b91`, with the Wave 2 actual WASM and node_modules available at the paths in the script and the retained genuine export at `/tmp/senkei-wave2-real.json`, run `scripts/performance/run.sh`. Override `SENKEI_BENCH_WASM_DIR`, `SENKEI_BENCH_NODE_MODULES`, `SENKEI_REAL_EXPERIMENT_ARTIFACT`, `SENKEI_BROWSER_PORT`, or `SENKEI_PERFORMANCE_OUTPUT` as needed. The runner temporarily applies `instrumentation.patch`, builds, runs the existing real-Worker semantic incompatible-import browser test with its original deadlines, captures raw console and environment evidence, and restores the patch and temporary links on normal exit or failure. This is diagnostic instrumentation, so its results are not a substitute for the final uninstrumented regression run.
