# 3D制作契約

## 対象と正本

本制作は既存のFaceted Low-Poly Stylized 3Dを、Hero展示と実Battlefieldで共通に使える品質へ改善する。
単一PR内でF01/R01の先行2体の造形と実画面を評価してから、残り10体へ展開する。
ユーザーの追加指示により、既存役割、装備、シルエット、画風規則から具体的な造形を進める。
本書は制作順序と確認方法を具体化するもので、未確定のキャラクターデザインを確定する権限を持たない。

別プロジェクトのキャラクターは本制作の対象外とし、参照、対応付け、探索を行わない。

## 12体の部位別制作仕様

以下の「実装」は `bfb0428` のGeneratorに存在する形状を指し、Visualの合格を意味しない。
「制作案」は既存の輪郭を保ちながら次に作る、または調整する形状であり、実装済みとは数えない。
役割から性格、年齢、種族、出自を追加しない。
顔の個体差は頭装備から見える面の構成として設計し、別作品の人物へ対応付けない。

共通の実装は `addHumanoidBody`、頭髪と頭装備は `addHeadgear`、胸部は `addHeroChestArmor`、武器と付属品は `addHeroLoadout` にある。
顔は顎、頬、額、頭頂を通る5段の断面、左右の耳、鼻の楔、面に沿う目、眉、口からなる。
`bfb0428` では顔面の平面変化に沿う細分化した目と口へ変更したが、12体の固有顔を作り分けた実装ではない。
頭髪も共通の暗褐色3段ボリュームが基本で、F04にだけ追加の横へ伸びる毛束がある。
露出しない髪を「確認済み」と扱わず、兜やフードからの貫通、頭皮との隙間、側面の厚みを撮影する。

体幹は腰の上に胸郭が広がる断面と、独立した骨盤で作られている。
腕は肩、上腕、前腕、手、脚は腿、膝を支点とする脛、前へ出た爪先を持つブーツに分かれる。
R01以外には共通の肩鎧、前腕鎧、腿鎧、膝当て、脛当てがあり、全身を個別に作り直した状態ではない。
R01は布袖と裾へ分岐し、これらの鎧を付けない。
手は現状では革材質の塊であり、独立した指や武器を巻く指の実装を前提にしない。
制作では掌と柄の接点、手首から前腕への絞り、膝の屈曲位置を優先する。

各項の数値は `HERO_BODY_PROPORTIONS` の相対値である。
胴は幅／高さ／厚み、腕は幅／長さ／厚み、頭は一様倍率、脚は長さと左右の開きを記す。
さらに `build` が体幹と四肢の一部へ入るため、これらを最終寸法や頭身とみなさない。
実際の合成と初期姿勢はGeneratorを正本とする。
個別チェックに加えて、全員について正面、背面、左右側面、斜め、近景と戦場、Pixel/Smooth、全LOD、5ポーズと実動作の接地を確認する。
以下のチェックは全件未完了から開始し、画像と観測を状態表へ添えて判定する。

### F01 Bannerhold

- **頭と髪（実装）**：頭0.96。金属兜は上へ絞る4断面、前額の金縁、暗いバイザー、短い中央稜を持つ。髪は共通の短い暗褐色体積が兜内にある。制作案はバイザー下の頬と顎を明確にし、眉と金縁の重なりを整理する。
- **胴と骨盤（実装）**：build 1.03、胴1.07／1.02／1.03。胸甲は肩側の広い八角形から腹側の尖りへ絞り、中央に細い稜を重ねる。骨盤幅1.04。制作案は胸甲の厚みを側面に残し、中央稜を独立した盾に見せない。
- **腕と脚（実装）**：腕1／1／1、脚長0.98、開き0.19。左腕を盾側へ開き、左右の脚を前後にずらす。共通肩鎧と膝脛鎧を保持する。制作案は盾の裏から左前腕までの支持関係と剣の柄の接触を作る。
- **衣服、武器、装飾（実装）**：剣は直線の刃、盾は小型（full倍率0.82）の尖底形。腰前に分割布、背に長いマント、左背に旗竿と切欠き旗がある。マントは `bfb0428` で厚い平板から奥行きのある折り襞へ変更した。制作案は襟、留め具、肩から背への布の連続を整える。
- **輪郭の境界**：中幅の指揮体幹、左の盾、右の剣、左背の旗、短い兜稜を保持する。F02の大盾と最大幅の体型へ寄せない。

個別受入：

- [ ] 金縁とバイザーが目を余分な浮いた板に見せず、顎と鼻が斜め近景で読める。
- [ ] 剣と盾が両手へ接続し、攻撃中も盾が腕や胸を不自然に切らない。
- [ ] 後方の旗とマントの折り襞が別の奥行きにあり、側面で板1枚に潰れない。

### F02 Stoneheart

- **頭と髪（実装）**：頭0.9。幅広い金属兜、暗い横長の面覆い、左右上方へ伸びる金属突起。共通髪を兜内に収める。制作案は小さめの頭を維持し、面覆いと頬の奥行きを分ける。
- **胴と骨盤（実装）**：build 1.18、胴1.2／0.98／1.12、骨盤幅1.16。胸甲は左右に張る上縁と厚み0.095の広い板、中央を横切る補強板。制作案は胸と腹の段差を残し、鎧全体を球状に膨らませない。
- **腕と脚（実装）**：腕1.12／0.96／1.08、脚長0.93、開き0.23。12体中でも広い支持幅と短めの四肢。共通鎧を拡幅する。制作案は大盾を支える肘、手首、踏ん張る膝の間隔を明確にする。
- **衣服、武器、装飾（実装）**：右の直剣、左の大盾（full倍率1.22）、分割腰布、長いマント。兜の左右突起が主要装飾で旗はない。制作案は大盾の縁、裏面、把持部を整理し、マントの側面厚みを改善する。
- **輪郭の境界**：低重心の幅広い胴、大盾、小頭を一組で保持する。F01へ旗を追加した色違いにしない。

個別受入：

- [ ] F01と同じ画面サイズでも大盾と胴幅の差が読める。
- [ ] 大盾が脚を完全に隠さず、支持脚と地面の接点が側面でも追える。
- [ ] 左右の兜突起と胸甲の厚みが全方向で閉じ、鎧と髪が貫通しない。

### F03 Breach

- **頭と髪（実装）**：頭0.96。金属兜、額当て、陣営色の高い中央飾り稜（高さ0.34）。髪は共通体積。制作案は稜の付け根を兜へ接続し、頭頂を伸ばした髪に見せない。
- **胴と骨盤（実装）**：build 0.95、胴1.04／1.01／1.04、骨盤幅0.96。胸甲は上が広く腹へ細く伸びる形で片側に斜め革帯。制作案は革帯と胸甲の重なりを低い段差で表す。
- **腕と脚（実装）**：腕1.04／1.04／1.02、脚長0.97、開き0.21。胴を前へ傾け、右腕と槍を傾ける。共通鎧を保持。制作案は長柄の握りと肩肘の方向を合わせ、前傾でも接地を保つ。
- **衣服、武器、装飾（実装）**：マントなし、分割腰布、長い木柄と金属穂先、穂下の小旗、左手の小型装甲板。制作案は槍柄の直線と穂先の厚みを維持し、小旗を刃と分離する。
- **輪郭の境界**：高い兜稜と細長い槍、前傾の体幹、露出した背を保持する。旗竿や大盾を追加しない。

個別受入：

- [ ] 槍の穂先、柄、小旗が別の形として読め、手から柄が浮かない。
- [ ] 前傾で腿と腹が貫通せず、左右の膝と足裏が追える。
- [ ] 背面でマントがなく、胸の斜め帯と高い兜稜で識別できる。

### F04 Rook

- **頭と髪（実装）**：頭0.98。片側へ傾いた布帽と額帯、共通髪に加えて反対側へ上がる暗色毛束。制作案は毛束の根元から先端への段階的な絞りを保ち、帽子と髪の継ぎ目を側面で閉じる。
- **胴と骨盤（実装）**：build 0.82、胴0.88／1.08／0.92、骨盤幅0.9。交差する2本の革帯と小さい中央胸甲。制作案は細い腹と胸郭を区別し、交差帯の中心を大きな金属板で覆わない。
- **腕と脚（実装）**：腕0.91／1.06／0.92、脚長0.95、開き0.185。胴を捻り、左右の腕と武器を反対向きに開く。共通鎧は存在する。制作案は両刃の空間と肘の可動域を確保し、肩鎧の幅で細身を失わない。
- **衣服、武器、装飾（実装）**：マントなし、腰の分割布、左右の湾曲剣。追加の背負い装備はない。制作案は2本とも鍔と柄を持つ長い剣として仕上げ、R03の短剣と区別する。
- **輪郭の境界**：細長い胴、左右へ開く長い湾曲剣、非対称の帽子と毛束を保持する。

個別受入：

- [ ] 2本の湾曲剣が左右の手から別々に伸び、胸の前で一枚の塊に重ならない。
- [ ] 毛束と傾いた帽子の左右差が背面と側面でも残る。
- [ ] R03と並べた際に身長印象、前傾量、刃の長さが区別できる。

### F05 Lockstep

- **頭と髪（実装）**：頭1.02。幅0.33まで張る鍔から尖った頂点へ絞る布帽、前面の帯。髪は共通の短い体積。制作案は鍔の裏を閉じ、目と眉に影が重なっても顔面の板が突出しないよう整える。
- **胴と骨盤（実装）**：build 0.91、胴0.96／1.02／0.98、骨盤幅0.96。胸に3段の横長装甲板が下へ狭まりながら重なる。制作案は各段の端と下の衣服の隙間を揃える。
- **腕と脚（実装）**：腕0.95／1.01／0.96、脚長0.96、開き0.19。軽い胴の捻りと前後にずらす脚、傾けた右の刀。共通鎧。制作案は抜いた刀の柄と右手を合わせ、空いた左手の姿勢を整理する。
- **衣服、武器、装飾（実装）**：湾曲した片刃表現の刀、左後方を斜めに通る細い鞘、長いマント、分割腰布。制作案は鞘の口と刀の形を区別し、マント内への埋没を避ける。
- **輪郭の境界**：幅広い帽子、段状の胸甲、刀1本と背後の鞘を保持する。双剣や槍へ置き換えない。

個別受入：

- [ ] 帽子の鍔が横と背から見ても厚みを持ち、顔へ刺さらない。
- [ ] 胸の3段と腰布が一枚の縞模様にならず、実際の端面を持つ。
- [ ] 刀、鞘、マントが側面で分離し、動作中の腰と手へ貫通しない。

### F06 Pathfinder

- **頭と髪（実装）**：頭0.94。金属兜の左右に横へ張る翼形板、中央の低い稜。髪は共通体積。制作案は翼を厚い金属装飾として接続し、生物の翼や耳の設定を追加しない。
- **胴と骨盤（実装）**：build 1.04、胴1.08／1.04／1.04、骨盤幅1.06。非対称な胸甲と上から下へ横切る革帯。制作案は胸甲の左右差を全身の動きに残し、帯を浮かせない。
- **腕と脚（実装）**：腕1.03／1.02／1.02、脚長0.98、開き0.205。前傾した胴、左右を前後にずらした脚。共通鎧。武器キーはtwo-hand-maulだが現在の槌は右手pivotに付き、左手の両手把持は未保証。制作案は支持する左手の位置を実動作で解く。
- **衣服、武器、装飾（実装）**：長柄の大槌と金属の横広い槌頭、右背の旗、長いマント、分割腰布。制作案は槌頭の厚み、柄の握り、右背の旗との間隔を整える。
- **輪郭の境界**：翼兜、大槌、右背の旗を保持する。偵察役という理由で弓や軽装へ変更しない。

個別受入：

- [ ] 槌頭の面と厚みが側面で読め、柄が手とつながる。
- [ ] 両手把持を採用する場合は全ポーズで支持手の接点を確認し、未成立の片手状態を隠さない。
- [ ] 翼兜と旗が重ならず、F01の剣盾と左背旗から識別できる。

### R01 Tempest

- **頭と髪（実装）**：頭1.03。頭上で尖る布フードと首回りの布輪、内側に共通髪。制作案は顔を囲む開口と後頭部の厚みをつなぎ、顔の目と口がフードの前に浮く板に見えないよう整える。
- **胴と骨盤（実装）**：build 0.88、胴0.93／1.08／0.94、骨盤幅0.92。`bfb0428` で胸の盾形装甲を布チュニックと細い織り帯へ変更した。制作案は襟から帯、腰への縦の流れを保ち、胸を金属の盾に戻さない。
- **腕と脚（実装）**：腕0.91／1.08／0.93、脚長0.94、開き0.18。`bfb0428` で肩と前腕を布袖へ変更し、腿、膝、脛の装甲を除いた。腿とブーツの骨格は残る。制作案は袖口から手への絞りと、裾の内側を通る足の接地を確認する。
- **衣服、武器、装飾（実装）**：腰から広がる10角断面の長い布裾、奥行きのあるマントの折り襞、木杖、分節した金属の杖頭、低輝度の球。杖に大きな輪はない。制作案は布裾と後ろのマントを別の層として扱い、歩行中の脚抜けを解く。
- **輪郭の境界**：細長い布主体の胴、袖、広がる裾、フード、縦の杖を保持する。F01と共通の肩鎧や鎧の分割腰へ戻さない。

個別受入：

- [ ] 顔の目と口が頬面に沿い、フード開口、髪、耳と干渉しない。
- [ ] F01との並列で肩、胸、腰裾が布主体と読め、鎧の色替えに見えない。

### LODへの引き継ぎと省略の境界

full、medium、farは同じ12体の頭装備と体型を生成する。
mediumは共通の細部を減らし、farでは `addHeroFarLoadout` に切り替える。
現状のfarは主要武器を残す一方、F03の小型副装甲、F05の鞘、R02の背ボルト、R03の追加背布、R05の袋、R06の矢と矢筒を省略する。
F01/F06の旗も簡略な旗面へ置き換える。
これらは実装上の省略であり、識別を保てたという受入結果ではない。
各Heroの主要な体型、頭装備、武器の輪郭で識別できるかを戦場の実サイズで判定し、省略で識別を失う場合はfarの形を修正する。
個体差を示す新しい顔や毛束を採用する場合も、近景の追加と遠景の保持範囲を分けて記録する。

## 共通制作と描画の契約

- 顔、鎧、布、革、武器の体積と面方向を実Geometryで作る。三角模様やPixel処理だけでfaceted表現を代替しない。
- Hero展示と戦場は同じ `buildBattlefieldHero` 系列、appearance identity、材質、動作意味を使う。撮影専用の別モデルを作らない。
- Generator名と版、assetKey、appearanceKey、材質、LOD、アニメーション、生成元、ライセンスを追跡する。形状を変更した場合は対応する生成版を更新する。
- LODは近景の詳細、遠景の輪郭、画面占有サイズを考慮する。武器、頭装備、主要装備を保持し、切替時の姿勢や接地の飛びを確認する。
- Minionは現行Catalogのmelee/ranged、Monsterはgrove-brute/iron-warden/storm-stalkerを対象とする。Rendererにsiegeの実装があっても、現行Catalogに存在するMinionとして追加しない。
- 地形は3レーン、2ジャングル、4キャンプ、斜行河川、橋3、橋なし渡河2、河上MID基地、両本拠地を立体で読み分ける。既存Worldの公開Presentationと整合させる。
- 塔、拠点、橋、基地は基礎と上部構造、材質、旗、損傷の意味が形で伝わるようにする。装飾で架空の通路や橋を作らない。
- 全表示モードとLODは同じ認可済みReplayを使い、未知状態を補完しない。攻撃、被害、破壊、復活は確定イベントに同期する。
- Presentation変更で論理距離、worldLogicDigest、試合結果、CU、権限を変えない。UI文字は高解像度で保つ。

## 実画面の証拠と判定

各証拠にはbuildのHEAD SHA、capture source SHA、URL、Viewport、Tick、カメラ、Pixel/Smooth、Tactical/Cinematic、Replay/scenario identityを記録する。
同一試合の初期、交戦、横断、通常橋、拡張橋、破壊橋、徒歩渡河、基地争奪、終局を既存の実Jinrei→Enbu/WASM→PresentationReplay→Rendererで検証する。
Fixtureは再現と造形確認を補助するが、本番実戦の証拠を代替しない。

| 確認 | 証拠と判定条件 |
| --- | --- |
| Hero近景とLOD | 先行2体の各方向、全12体の一覧、個別近景、Follow/Tactical。同一identity、輪郭、装備、面構成、材質、貫通、接地を目視 |
| 地形と建築 | Overview/Tactical/Follow。BATTLEFIELD-VISUALの各地理要素と橋状態を実画面で確認 |
| UIと操作 | 1440×900、1920×1080、390×844、430×932、幅320px。再生、停止、シーク、速度、選択、カメラ、Details/Timeline往復 |
| 描画方式 | Pixel/Smooth、Tactical/Cinematic、情報レイヤー切替。視認性と認可状態が一致 |
| 動作 | idle、移動、停止攻撃、被弾、skill、死亡、復活。確認可能な実イベントに限定し、欠けたイベントは未確認 |
| 性能 | FPS、メモリ、draw call、密集時のLODを計測。SwiftShaderと物理GPUを区別し、実機タッチは別記録 |

Functional、Visual、Interaction、CI、Performanceは別列で判定する。
証拠の存在、メッシュ数、build成功、テスト成功だけでVisualをPASSにしない。
未確認は `NOT_CHECKED`、確認した具体的未達は `FAIL`、実行環境の不足は `BLOCKED_BY_ENVIRONMENT` とする。
VisualのPASSには評価対象、観測結果、既知の制約を併記する。
